# HappyMax — главный сайт (хаб направлений)

Главный лендинг **HappyMax Handyman Service** с пятью вкладками сверху —
по одной на каждое направление:

| Вкладка | Папка | Куда ведёт главная кнопка | Телефон |
|---|---|---|---|
| Auto Detailing | `auto-detailing/` | happymaxautodetailing.com (живой сайт) | (808) 452-0002 |
| Yachts | `yachts/` | звонок / SMS — отдельного сайта пока нет | (808) 452-0002 |
| For Home (deep cleaning) | `home-cleaning/` | звонок / SMS — отдельного сайта пока нет | (808) 201-1311 |
| For Business (commercial cleaning) | `business-cleaning/` | звонок / SMS — отдельного сайта пока нет | (808) 201-1311 |
| TV Mounting | `tv-mounting/` | happymaxhandymanservice.com (живой сайт) | (808) 201-1311 |

Статика: HTML + CSS, без JavaScript и без форм — сайт ничего не собирает
и ни к какому бэкенду (Supabase, Telegram) не подключён.

## Как править

Весь текст, телефоны, почты и ссылки — в **`build.py`**. После правки:

```
py build.py
```

Скрипт пересобирает `index.html` и пять папок разделов. HTML-файлы руками
не править — следующая сборка их перезапишет.

- Появился отдельный сайт для яхт / уборки → вписать адрес в поле `"site"`
  нужного раздела в `SERVICES`; кнопка «перейти на сайт» появится сама.
- Сменился телефон → блок `CONTACTS`.
- Правишь `assets/css/style.css` → подними `ASSET_VERSION` в `build.py`
  (иначе вернувшиеся посетители увидят старые стили из кэша).

## Деплой

Push в `main` → GitHub Pages. Пока без своего домена.
Свой домен — файл `CNAME` в корне + DNS у регистратора.

## ⚖️ Юридические правила (Гавайи) — действуют и здесь

- Никогда не писать «Licensed», «Licensed & Insured». Владелец не имеет
  лицензии подрядчика (HRS §444-9.2 — реклама без лицензии = misdemeanor).
- TV mounting — только в рамках handyman-исключения §444-2: до $1,500,
  без разрешений на строительство, без электрики и сантехники.
- Никаких выдуманных отзывов, рейтингов, «500+ клиентов».
- Цены, гарантии, сроки ответа — только подтверждённые владельцем.
